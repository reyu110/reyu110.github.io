Niche Communities

Where does the audience for a topic actually gather online, and who matters there? This is a small project that answers that for any niche, and keeps answering it as things change.

Read the full project report →

What it does

Give it a niche and it finds the communities and creators around it on YouTube, TikTok, Instagram and X. It ranks who matters on each platform, saves a dated snapshot every day, and shows how audiences grow or shrink over time.

Watching Google

For a website it tracks search rankings and page health, and says what to fix when they slip. With Google Search Console connected it reads real clicks, impressions and indexing status instead of estimating them. It can also write a ready-to-use change list for a page: a new title, description and headings, shown beside the old ones.

Working with creators

It helps shortlist creators, draft a message to each, take applications and follow how a creator's audience moves after support. It records what you did; it never sends messages or moves money.

How it is built

It is a small Python and Streamlit application that runs on one computer and keeps everything in a single SQLite file. It uses free tiers where it can and shows an estimate before anything that costs money.
